# Ross-cripto/homebrew-tap

Homebrew formulae for [strata](https://github.com/Ross-cripto/strata), the living map of your app's use cases in the terminal.

```sh
brew install Ross-cripto/tap/strata
```

`Formula/strata.rb` is generated by each strata release. The Sync workflow copies it from the latest release every day; run it by hand to publish a release at once:

```sh
gh workflow run sync.yml -R Ross-cripto/homebrew-tap
```
