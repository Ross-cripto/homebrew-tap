# Ross-cripto/homebrew-tap

Homebrew formulae for [casemap](https://github.com/Ross-cripto/casemap), the living map of your app's use cases in the terminal.

```sh
brew install Ross-cripto/tap/casemap
```

`Formula/casemap.rb` is generated by each casemap release. The Sync workflow copies it from the latest release every day; run it by hand to publish a release at once:

```sh
gh workflow run sync.yml -R Ross-cripto/homebrew-tap
```
